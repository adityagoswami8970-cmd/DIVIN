# Divine Essentials

A responsive storefront concept for a spiritual lifestyle and pooja essentials shop.

## Run locally

Open `index.html` in a browser. Product discovery, category filters, search, favourites, and a local-storage shopping bag work without a build step.

## Notes

- Product photography and web fonts are loaded from Unsplash and Google Fonts, so an internet connection is needed for those assets.
- Checkout is a front-end placeholder; connect a payment provider and order backend before accepting real orders.
